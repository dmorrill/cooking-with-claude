## Notes

### Organization
- Recipes are now organized into category folders for easier browsing
- Each recipe is a standalone markdown file with a human-friendly filename
- The original `recipe-database.md` is preserved as backup

### Recipe Format
Each recipe includes:
- Prep and cook times
- Difficulty level
- Ingredient locations (referencing inventory system)
- Detailed instructions
- Notes and tips

### Contributing
When adding new recipes:
1. Use the template format from any existing recipe
2. Place in the appropriate category folder
3. Update this README index
4. Include ingredient storage locations
