## How This Works
- **Lunch / Dinner**: what you're eating. Leave blank until planned.
- **Home?**: ✓ = cooking at home, ✗ = out/other plans, ? = TBD
- **Leftovers**: mark with 🔄 when a meal uses leftovers from an earlier one
- The MCP server's `get_meal_plan`, `set_meal` and `clear_meal` tools read and edit this table. Keep the `| Mon 9/28 |` date format so it can find each row. Add a new week's table when the week turns over.
